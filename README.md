# RealTrip · 实景自由漫游

线上站点：https://realtrip-walk.onrender.com/

当前提供四个场景：
- 荣誉连廊：`/honor-corridor/?scene=honor-corridor`
- 2号楼（默认）：`/?scene=building2`；旧 `?scene=insta360` 兼容。
- 露台：`/?scene=terrace`
- 食堂去人版：`/?scene=cafeteria`；保留人物版：`/?scene=cafeteria-original`

2026-10-17 已清理六个旧场景的入口、配置、专用资源与构建依赖。桌面移动、手机摇杆、转头、跳跃、横屏，以及三个场景的现有模型和碰撞校准继续保留。

## 界面更新

场景切换使用统一的深灰半透明面板，显示当前空间、图标与简短说明；支持键盘、点击外部关闭和 Escape。底部提示根据输入方式自动切换：电脑显示「WASD 移动｜空格跳跃｜拖动环视」，手机/平板显示「左侧摇杆移动｜右侧滑动转头｜轻点画面跳跃」。连接键盘、鼠标或切回触屏后，提示随实际操作更新，操作栏只保留复位；已移除单独跳跃和全屏/横屏按钮。手机可用摇杆移动、右侧滑动环视、轻点画面跳跃，自然横竖屏布局继续适配安全区。打开菜单时停止移动，避免方向键操作菜单时误走动。

构建与导航测试通过，已验证场景切换、摇杆、空格跳跃和复位。浏览器视口检查不替代真实手机验收。原模型、地面和碰撞参数不变。

## 部署

沿用现有 Render 静态站点 realtrip-walk，main 分支，自动部署关闭。

构建命令：`unzip -o realtrip-render.zip -d site && cd site && npm ci && npm run build`

发布目录：`site/public`。构建先清理 public 中不再发布的旧路径，再校验并装配以下模型，最后重新生成查看器。

- `building2-doorway-20261017.sog`
- `terrace-20261017.sog`
- `cafeteria-20261017.sog`
- `cafeteria-original-20261017.sog`
- `honor-corridor-20261017-return-feedback.sog.part001` 至 `.part003`

模型的大小和 SHA-256 在包内准备脚本中校验。其他保留的旧模型仅用于版本回退，不复制到线上 public。

## 食堂（2026-10-17）

用户提供的食堂分享模型已接入自由步行、摇杆、跳跃、回起点与横竖屏；默认清晰，沿用简洁场景菜单。按原拍摄视点校准眼高与地面，对取餐台、立柱、排队栏杆与扫描边界设置简化碰撞。入口、主通道、取餐通道及中央区域支持往返。远处未完整扫描的就餐区保持为背景。

模型中可见人员与局部残影经过空间范围和视角轮廓清理，其他点的几何、颜色及纹理保持原样。人员遮挡位置仍有缺损，未合成虚构背景。来源、模型哈希与清理记录保存在 `public/cafeteria/`。

验证：发布包构建、全部回归检查通过；844×390 横屏摇杆从入口走到主通道并原路返回，复位准确；390×844 竖屏布局正常。这里是浏览器尺寸模拟，未宣称真机性能验证。

## 输入方式适配（2026-10-17）

初始提示通过主要指针能力识别触控设备，后续根据触摸、鼠标与移动按键切换。屏幕尺寸仅决定布局，因此缩小电脑窗口不会误显示手机操作。手机竖屏提示放在摇杆上方，横屏位于两侧控件之间。

输入提示的初始识别、混合输入切换、能力变化与监听清理测试通过。390×844、320×568、844×390 触控提示布局使用本地测试夹具模拟检查；没有将模拟代码发布，尚未进行实体手机验收。
