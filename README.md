## 构建与发布

现有 Render 静态站点使用 `main` 分支，手动触发部署。

```sh
unzip -o realtrip-render.zip -d site
cd site
npm ci
npm run build
npm test
```

工位模型单独存放以便网页上传；构建脚本校验其 SHA256 并复制到发布目录，两个文件须一并保留在仓库根目录。

发布目录为 `site/public`。包内同时包含 `/luzhai.html` 和 `/luzhai/index.html`，支持直接访问卢宅入口。
