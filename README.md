# RealTrip · 实景自由漫游

线上站点：https://realtrip-walk.onrender.com/

当前提供四个场景：
- 荣誉连廊：`/honor-corridor/?scene=honor-corridor`
- 2号楼（默认）：`/?scene=building2`；旧 `?scene=insta360` 兼容。
- 露台：`/?scene=terrace`
- 食堂：`/?scene=cafeteria`，保留人物；旧 `?scene=cafeteria-original` 自动兼容到同一场景。

2026-10-17 已清理六个旧场景的入口、配置、专用资源与构建依赖。桌面移动、手机摇杆、转头、跳跃、横屏，以及三个场景的现有模型和碰撞校准继续保留。

## 界面更新

场景切换使用统一的深灰半透明面板，显示当前空间、图标与简短说明；支持键盘、点击外部关闭和 Escape。已移除底部操作提示，操作栏只保留复位；已移除单独跳跃和全屏/横屏按钮。手机可用摇杆移动、右侧滑动环视、轻点画面跳跃，自然横竖屏布局继续适配安全区。打开菜单时停止移动，避免方向键操作菜单时误走动。

构建与导航测试通过，已验证场景切换、摇杆、空格跳跃和复位。浏览器视口检查不替代真实手机验收。其他场景的模型、地面和碰撞参数不变。食堂新增补拍用餐区域。

## 部署

沿用现有 Render 静态站点 realtrip-walk，main 分支，自动部署关闭。

构建命令：`unzip -o realtrip-render.zip -d site && cd site && npm ci && npm run build`

发布目录：`site/public`。构建先清理 public 中不再发布的旧路径，再校验并装配以下模型，最后重新生成查看器。

- `building2-doorway-20261017.sog`
- `terrace-20261017.sog`
- `cafeteria-counter-detail-20261017.sog`
- `cafeteria-dining-detail-20261017.sog`
- `honor-corridor-20261017-return-feedback.sog.part001` 至 `.part003`

模型的大小和 SHA-256 在包内准备脚本中校验。其他保留的旧模型仅用于版本回退，不复制到线上 public。

## 食堂补拍接入（2026-10-17）

用户选择保留人物。菜单仅保留一个「食堂」，原去人版已撤下；两个旧食堂入口都进入当前场景。

原始素材 `GS3DC1ec046bfbacc4d3c9e43a26763aa410e` 负责取餐区，补拍素材 `GS3DC9401fd20afb548cd8bfa6f5b31b8458a` 负责餐桌区与中央柜台。两份模型通过地面、静态结构对齐，按空间分区裁剪后同时渲染，跨区域不切换相机或页面。保留人物与原有运动残影，保留点的几何、颜色、透明度与球谐属性逐字节验证一致，未合成背景。总计 1,310,556 个点。

原有眼高和取餐区碰撞保持不变，新增餐桌旁过道和整体桌椅阻挡；入口、餐桌旁、取餐通道可以往返。远处尚未充分拍摄的座位区仍未开放。简化碰撞和尺度估算不代表实测建筑尺寸。

模型清单及 SHA-256 位于 `scripts/cafeteria-models.json`，素材来源和对齐参数位于 `public/cafeteria/provenance.json`。构建校验两份模型并移除旧对比资源；加载完成后统一启用移动。

验证：构建与全部回归测试通过，覆盖已有路线、新增餐桌方向双向通行、桌椅阻挡、模型哈希及人物保留。844×390 浏览器中使用摇杆从入口走至餐桌过道深处并原路返回，地面高度持续稳定；自然横竖屏仍适配。浏览器尺寸检查不替代实体手机性能验收。

保留人物。对比两份原始模型的七个匹配视角后，入口凳面及附近地面、白衣用餐人物的头肩采用较完整的原素材；另一位人物、餐桌远侧、人物下半身与后排用餐区沿用补拍。采用互补区域选择，同一部位不同时叠加两个拍摄时刻，也不随转头切换模型。保留点的几何、颜色、透明度和球谐编码未重新压缩。

总点数 1312985，与上一版约 131 万点相当。地面、桌椅碰撞和通行路线保持不变。侧后方仍有源素材的运动残影，未生成或杜撰人物面部。模型范围和哈希记录在 provenance.json，回退基线为 2f9979c0dc23abf6b0efbf9ccbcc44766e59236f。
